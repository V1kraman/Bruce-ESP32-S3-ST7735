# Bruce V2 ST7735 5-Button Prototype Archive

This folder is the complete documentation package for the **ESP32-S3 N8R8 + 1.8-inch ST7735R + 5-button Bruce V2 prototype**.

## Start here

1. Open `README.md` for the complete project retrospective.
2. Open `docs/wiring-guide.md` for the condensed wiring instructions.
3. Open `docs/troubleshooting.md` for the main problems and fixes.
4. Open `docs/build-log.md` for the build history.
5. Browse `images/` for the actual prototype photographs.
6. Browse `diagrams/` for generated diagrams and retained reference wiring diagrams.
7. `reference_firmware/current_breadboard_source.zip` contains the source archive associated with the breadboard project.
8. `reference_firmware/fixed_v2_reference.zip` contains the later fixed-v2 reference package and its wiring diagrams.
